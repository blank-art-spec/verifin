## 数据与估值

`MarketQuoteRequest` 仅含公开代码、市场、币种、品种及证券 ID，不包含账本/账户、数量、余额、成本或备注。每来源按当前持仓合并最多 20 个身份，来源请求串行，每批总超时 15 秒；不存在全市场下载再筛持仓。未来 I/O 适配器还必须采用固定 HTTPS 主机、流式 512 KiB 上限、不跟随非白名单跳转、不带凭证、不绕过访问拒绝，才可通过评审；当前自动客户端没有生产 I/O 路径，既有独立研究客户端的 15 秒/512 KiB 约束保留。

`MarketQuote` 保存证券、来源、原币、每股/每权利金单位、最近成交/买价/卖价及各自时间、抓取时间、来源声明延迟和交易状态。股票采用带源时间的正成交价；期权优先有效双边中间价，否则采用带时间的正成交价。倒挂或零买价不计算中间价，缺时间/错误单位/错误币种/非有限或负价格/明显未来时间不可估值；网络零报价不触发自动清仓。

`InvestmentPortfolio.marketPriceIds` 是用户明确选择采用行情的证券集合，默认空；完整备份保存选择及原手填后备值。合格缓存只用于只读派生 `pricedInvestmentPortfolio`，不覆写 `manualPrices`，也不修改成交、数量、成本或现金。用户在持仓卡“改为手填参考价”后持续覆盖；网络恢复不会自动撤销。缓存缺失/源失败时使用明确的手填后备价并显示状态，不能把未知价变为零。

偏好和缓存走设备 KV，不进账目备份。缓存最多 100 项、512 KiB，串行持久化，只保存公开报价及账务上下文摘要，不复制原始持仓。冷启动不联网，读取缓存仍重新校验来源门禁和证券身份；损坏缓存可丢弃，原 SQLite 不变。关闭联网保留既有参考缓存，缓存写入失败明确“当前只在内存”，不能假报持久保存。

## 生命周期与在途结果

只有行情页面处于前台、当前路由可见且 `AppUnlockScope` 解锁时才能请求。默认进入时检查缓存/冷却并可手动刷新；可选每五分钟仅当前页刷新，离页、退后台及锁屏停止计时并撤销请求修订，不申请后台权限或常驻服务。

请求前、返回后、缓存提交前均复核启用状态、当前可见账户及同一不可变聚合实例。偏好写入串行，较慢的开启确认不能覆盖稍后的关闭意图。后台创建页面也不发请求。关闭开关立即撤销在途修订；切换账本、删除持仓、导入/恢复或初始化后旧响应失效。较旧源时间不得覆盖较新缓存。真实恢复才清缓存并保留本机授权偏好，导入预览保持零写入；新设备默认关闭。

状态通过独立 `ValueNotifier<QuoteSyncState>` 通知进度/偏好，只有接受的价格影响资产时才通知现有账目消费者。`formatQuoteTime` 统一应用语言/设备时区，明确来源和抓取时间，不把缓存成功解释为实时。
