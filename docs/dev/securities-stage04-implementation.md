## 当前交付边界

已实现参考报价协议、来源分发门禁、设备短缓存、持续手填覆盖、应用前台会话刷新、按账户独立的自动计时、生命周期和旧响应隔离；接入投资页及当前账户资产读取。手动刷新取消应用本地五分钟等待，自动刷新默认仍为每五分钟一次。

**当前普通构建仍没有已获正式发布准入的自动估值来源。** 诊断研究来源包含腾讯真实股票与招商官方指定美元货币基金 B 类；只有实际 debug、独立 `diagnostic` flavor 和显式 `PUBLIC_QUOTE_RESEARCH=true` 三项同时满足才装配，联网开关仍默认关闭。腾讯沪深/香港股票协议的真实样本为中远海能与腾讯，美股仅接受 AVGO/GOOG；招商来源只接受已核对的 `HK0001039582`、USD、B 类单位净值，不扩展到其他基金或收益指标。期权和 TEST 合约不发请求。两来源均保持 `approved: false`、`researchOnly: true`，免账号、免 Key、无自有后台；研究接入不等于生产或全品种准入。完整边界与证据分别见[腾讯股票研究](public-quote-research.md)和[招商基金研究](cms-fund-api-research.md)。手填参考价和离线账务继续完整可用。

## 数据与估值

`MarketQuoteRequest` 仅含公开代码、市场、币种、品种及证券 ID，不包含账本/账户、数量、余额、成本或备注。每来源按当前持仓合并最多 20 个身份，来源请求串行，每批总超时 15 秒；不存在全市场下载再筛持仓。腾讯研究适配器只访问固定 HTTPS 主机 `qt.gtimg.cn`，流式累计最多 512 KiB，不跟随跳转、不带凭证、不绕过 HTTP 拒绝；超时或超限关闭连接。该 I/O 路径仅由显式诊断研究工厂装配，普通构建没有已准入生产 I/O 来源。

招商基金研究只向固定主机 `cms.cmschina.com.hk` 的 `netVal-info` 发送公开基金参数和语言，
匹配指定 B 类的单位净值；原始 JSON 价格保留十进制文本，来源净值日期只有日精度，不能
补造盘中报价时刻。身份由已核对的官方基金参数与 B 类映射确定，响应未回显 ISIN/币种，
不能误称每次均由来源重新确认完整证券身份。`netVal-export` 的 XLS 仅用于研究对照，
不作为每次行情刷新的第二个请求，也不据此自动入账收益。

公开 NAV 历史使用既有设备报价缓存，按官方实际净值日及当日真实持仓实时派生参考收益和基金
历史市值；改删交易后重算，不生成收入流水或权威估值快照，不新增 SQLite 字段或再次提升
JSON v13。跨周末区间不拆成自然日收益；混合账户缺其他证券同日价格时完整账户历史资产未知，
不把今天的股票参考价回填历史。完整口径见[基金参考收益与资产口径](cms-fund-api-research.md#净值日参考收益与历史参考资产口径)。

`MarketQuote` 保存证券、来源、原币、每股/每份基金/每权利金单位、最近成交/买价/卖价及各自时间、抓取时间、来源声明延迟和交易状态。股票采用带源时间的正成交价；期权优先有效双边中间价，否则采用带时间的正成交价。基金净值使用独立 `fundUnit` 与 `dateOnly`，规范 UTC 年月日仅承载来源日历日，不表示午夜报价；显示及主动保存的历史依据都保留这项日精度。倒挂或零买价不计算中间价，缺时间/错误单位/错误币种/非有限或负价格/明显未来时间不可估值；网络零报价不触发自动清仓。

`InvestmentPortfolio.marketPriceIds` 是用户明确选择采用行情的证券集合，默认空；完整备份保存选择及原手填后备值。合格缓存只用于只读派生 `pricedInvestmentPortfolio`，不覆写 `manualPrices`，也不修改成交、数量、成本或现金。用户在持仓卡“改为手填参考价”后持续覆盖；网络恢复不会自动撤销。缓存缺失/源失败时使用明确的手填后备价并显示状态，不能把未知价变为零。

偏好和缓存走设备 KV，不进账目备份。缓存最多 100 项、512 KiB，串行持久化，只保存公开报价及账务上下文摘要，不复制原始持仓。缓存 v2 另保存按账本及账户区分的尝试时间和下次自动刷新时间；兼容 v1 报价行，旧全局时间不继续阻止各币种账户。冷启动不联网，读取缓存仍重新校验来源门禁和证券身份；损坏缓存可丢弃，原 SQLite 不变。关闭联网保留既有参考缓存，缓存写入失败明确“当前只在内存”，不能假报持久保存。

## 生命周期与在途结果

联网与自动刷新开关默认均关闭。开启后，由 `InvestmentQuoteSession` 在打开应用、回到前台或解锁时检查当前账本全部证券账户的已支持持仓；通过隐私同意与首次引导、应用处于前台解锁才允许请求，不再依赖进入参考行情页。每个账本及币种账户独立核对上次自动尝试时间，间隔取默认五分钟和来源要求中更严格的一方；仍在冷却时等待它原定的到期时间，切换账户不沿用另一账户的等待。前台会话持续有效时按各账户到期时间续刷。

`MarketQuoteSessionGate` 将根级生命周期和应用锁状态传入会话；`InvestmentQuoteSync` 分开处理应用会话与页面显示。手动点击仍只查询当前页面账户，不受应用本地五分钟限制，也不重置自动计时；同一账户请求未结束时防止重复发送。离开参考行情页不停止应用级自动刷新；退后台、锁屏、退出或关闭联网则停止后续调度并撤销在途结果，不申请后台权限或常驻服务。联网和自动开关仍为设备偏好；来源的实际 HTTP 拒绝和访问控制照常处理。

请求前、返回后、缓存提交前均复核启用状态、有效应用会话、请求所属账本/账户及同一不可变聚合实例。偏好写入串行，较慢的开启确认不能覆盖稍后的关闭意图。后台创建页面或控制器不触发查询。关闭开关立即撤销在途修订；切换账本、删除持仓、导入/恢复或初始化后旧响应失效。较旧源时间不得覆盖较新缓存。真实恢复才清缓存并保留本机授权偏好，导入预览保持零写入；新设备默认关闭。

状态通过独立 `ValueNotifier<QuoteSyncState>` 通知进度/偏好，刷新结果及尝试/自动计时随可见账户切换，只有接受的价格影响资产时才通知现有账目消费者。`formatQuoteTime` 统一应用语言/设备时区，明确来源和抓取时间，不把缓存成功解释为实时；来源价格及其时间相同时，有效的新请求仍更新抓取时间。

持仓卡将有效报价的来源与来源报价时间放在指标之后的独立次级信息区，复用
`InvestmentQuoteDetails`。`formatQuoteTime(compact: true)` 使用带年份的本地化短日期，
保留时刻、精度和设备时区；其他调用默认仍使用完整日期。来源名称与时间自然换行，
这项排版调整不改变报价采用选择、有效性判断、缓存或估值。

## 2026-10-27 真实股票研究接入

`production_market_quotes.dart` 的 `buildProductionMarketQuoteClient()` 只在正式入口装配本构建允许的来源；通用 Controller 的默认客户端仍为空，不因创建或冷启动自动联网。`TencentQuoteAdapter` 校验 GBK 响应中的市场、完整身份、币种、每股正价格与源时间；美股明确匹配 `.OQ` 身份，使用共享 `ensureTimezoneDatabase()` 的 IANA `America/New_York` 规则处理冬夏令时。没有来源时间时不以抓取时间代替。当前交易状态与标称延迟保持 unknown/null，不猜实时或开收盘。

页面显示研究范围，用户先主动开启联网，再逐证券选择“使用合格行情估值”；刷新只改变参考估值，不改现金、成交或手填后备价。请求、偏好恢复和缓存采用同一个来源可用性判断，普通/发行/无参数构建不会借用旧开关或研究缓存恢复联网。完整机制及实际执行结果集中在[诊断研究记录](public-quote-research.md)。

港股模板的两份 `TEST-TCH` 期权是本地虚构验收合约，没有真实挂牌身份；腾讯来源只支持股票，招商来源只匹配指定基金 B 类，均不向来源发送这些期权合约，也不把“不支持期权”归为临时网络错误。合约定义、手填价与已有期权账务保持不变。
