# 公开股票参考行情：诊断研究接入

更新日期：2026-10-27。本文记录免账号、免 API Key、无自有后台的真实股票查询验证，
配套机制见[参考行情阶段 4](securities-stage04-implementation.md)。

## 当前范围

新增 `TencentQuoteAdapter`，由 Android 客户端直接请求腾讯公开股票端点。
这是可显式装配的诊断研究来源，`QuoteSourceCapability.approved` 仍为 `false`，
`researchOnly` 为 `true`；技术可达和字段校验不等于已取得正式发布使用许可。

| 市场 | 研究适配器范围 | 本轮取得真实字段的标的 |
| --- | --- | --- |
| 沪深 A 股 | CNY 股票代码；沪市 6 开头、深市 0/3 开头 | 中远海能 `600026`，来源代码 `sh600026` |
| 港股 | HKD 普通股票代码，保留五位前导零 | 腾讯控股 `00700`，来源代码 `hk00700` |
| 美股 | 仅明确核对的 AVGO、GOOG，不声明覆盖全部美股 | `usAVGO`、`usGOOG`，响应身份须分别为 `AVGO.OQ`、`GOOG.OQ` |
| 期权及本地测试证券 | 不支持，不发请求 | `TEST-TCH…` 等合约始终保留手填参考价 |

沪深、香港代码协议可接受的范围，不代表所有个股都已在 Android 上逐一验收。
不接入港股人民币柜台，不把 GOOG 与 GOOGL、A 股 `600026` 与港股 `01138` 混用。
不因股票行情返回成功而自动创建或确认期权规格。

## 构建与启用边界

正式入口在 `main.dart` 调用 `buildProductionMarketQuoteClient()` 装配客户端。
研究来源只有同时满足下列三项才进入来源集合：

1. 实际为 debug 构建；
2. 使用独立 `diagnostic` flavor；
3. 显式传入 `--dart-define=PUBLIC_QUOTE_RESEARCH=true`。

`permitsQuoteResearch` 集中判断三项条件。正式渠道、release/R8、缺少显式参数的构建
都保持关闭，CI 发布命令不增加此研究参数。旧设备开关、缓存、导入 JSON 或用户填写的
标记不能把来源改成 `approved: true`，也不能代替构建条件。

通用 `VeriFinController` 的默认客户端仍为空，测试或其他控制器创建不会意外联网。
仅有适配器实例、创建控制器或冷启动应用也不会自动发请求。

用户明确需要诊断验证时，可手动运行：

```powershell
flutter run -d emulator-5556 --debug --flavor diagnostic --dart-define=UNIFIED_DESIGN_PREVIEW=true --dart-define=PUBLIC_QUOTE_RESEARCH=true
```

以上是一次手动命令，不建立自动构建任务。安装和运行继续遵守
[Android 开发约定](android-development.md)，使用独立包并保留已有数据。

## 使用流程与账务不变量

1. 进入真实币种账户的“证券投资 → 参考行情”，检查诊断研究说明和来源范围。
2. “开启参考行情联网”默认关闭。只有用户主动开启、页面在前台且应用已解锁时才查询。
3. 联网刷新与“使用合格行情估值”是两个选择。每只证券须单独启用后，合格报价才参与
   参考市值、资产和盈亏的只读计算；没有选择的证券持续使用原手填价。
4. 可手动刷新，并可另选仅当前页每五分钟刷新；冷却仍取五分钟与来源要求中更严格者。
5. 离页、退后台、锁屏或关闭联网后停止刷新并撤销旧响应；回前台仍核对当前账本、账户和持仓。

联网不会改写现金、历史成交、数量、成本、手续费或 `manualPrices`，不会把股票买卖
复制成普通收支。单只证券改回手填后持续覆盖，网络恢复不撤销该选择。
无效身份、缺价、零价、错误币种、缺报价时间或请求失败都不生成零估值或自动平仓。

设备短缓存和联网偏好仍保存在本机 KV，不进入完整账目备份；逐证券采用行情的选择和
手填后备价沿用既有备份字段。关闭联网可保留已校验参考缓存；没有合格报价时回退手填后备价。
关闭研究构建后，缓存仍须经过当前来源可用性校验，不能使普通构建恢复研究联网。

## 网络和解析约束

固定访问 `https://qt.gtimg.cn`，只请求当前账户持有且支持的股票身份；不发送账户名称、
账本 ID、余额、数量、成本或备注，不携带 Cookie、Authorization 或券商凭证。

- 去重后一次批量最多 20 个公开股票代码；不下载全市场列表再筛持仓。
- 整批请求与响应读取不超过 15 秒，流式累计最多 512 KiB；超时或超限立即关闭本批连接。
- 不跟随跳转，不绕过 HTTP 401/403 或其他访问拒绝，不更换身份反复重试。
- 按响应的 GBK 字节解析文本，不执行其中形似 JavaScript 的变量赋值。
- 来源代码、市场标识、币种和每股正价格都须匹配当前请求；未知行、重复身份及异常字段不成为有效观察。
- 源时间与抓取时间分开保存，不能用本机抓取时间代替报价时间。

当前适配器只取股票最近成交参考价，不猜测买卖价、开收盘或停牌状态。
`tradeState` 保持 `unknown`，`delayMinutes` 保持 `null`；页面如实提示状态或延迟未知。

## 源时间的一手依据

2026-10-27 开发机一次有界请求返回四只股票，HTTP 200、1,730 字节，
`Content-Type: text/html; charset=GBK`。价格仅是当时验证快照，不能作为今天或未来的现价承诺。

| 来源字段 | A 股 | 港股 | AVGO / GOOG |
| --- | --- | --- | --- |
| 身份位置 | 2：六位股票代码 | 2：五位股票代码 | 2：带 `.OQ` 的完整来源身份 |
| 每股成交价位置 | 3 | 3 | 3 |
| 报价时间位置 | 30：`yyyyMMddHHmmss` | 30：`yyyy/MM/dd HH:mm:ss` | 30：`yyyy-MM-dd HH:mm:ss` |
| 币种位置 | 82：CNY | 75：HKD | 35：USD |
| 时区解释 | UTC+8 | UTC+8 | `America/New_York` |

美股响应字段本身没有偏移和毫秒。[腾讯博通详情](https://gu.qq.com/usAVGO.OQ/gg)与
[谷歌-C 详情](https://gu.qq.com/usGOOG.OQ/gg)在对应报价旁标示 `Oct 26 4:00 PM EDT`，
并另列动态“美东时间”；该报价标签与响应中的 `2026-10-26 16:00:01` 对齐，
支持按纽约时区解释该来源的美股报价时间。动态当前时钟不能当成报价时间。

`timezone_database.dart` 的 `ensureTimezoneDatabase()` 与提醒调度共用既有完整
`assets/timezone/latest_all.tzf.gz`，不重复打包另一套时区表。美股按 IANA
`America/New_York` 转为 UTC，保留冬夏令时和历史规则，不固定减四/五小时。
沪深与香港的 UTC+8 换算也不读取手机当前时区。非法日期、缺时分秒和跳时异常不被自动修正。

腾讯网页的“该列表港股报价延时15分钟”仅明确其最近访问列表，不能据此断言该接口所有
字段的固定延迟，因此适配器不写死 15 分钟，也不把请求成功解释为实时。

最小公开响应夹具位于 `test/fixtures/investments/tencent_stocks_20261027.gbk`、
同名 `.txt` 及 `_metadata.json`。原始公开响应及官方页面时间证据位于被忽略的
`build/validation/quote-research-20261027/`，这些公开字段文件不包含用户账目或凭证。
设备验证快照另放在该目录的 `before-data/`、`after-data/`，仅保存在本机，不提交到仓库。

## 技术验证与正式发布的区别

本轮只确认免账号请求的技术可达、公开字段和源时间解释；没有找到允许第三方应用
自动使用腾讯财经数据的明确正式许可。腾讯来源持续标为“诊断研究”，不把用户同意联网
解释成数据供应方授权，不把此构建当作正式发布产物。

来源页面的[腾讯服务条款入口](https://www.qq.com/contract.shtml)仍需完成适用范围核对。
其他候选同样不能以公开可见代替许可：

- [HKEX 网站条款](https://www.hkex.com.hk/global/exchange/terms-of-use?sc_lang=en)限制未经许可的程序化访问，未把其网页抓取当作适配器。
- [东方财富服务条款](https://corp.eastmoney.com/fuwutiaokuan.html)限制行情再传播；本次匿名公开请求超时，不据此建立可用性承诺。
- Yahoo、Nasdaq 的已有待核对状态保持不变，详见[阶段 4](securities-stage04-implementation.md)。

正式渠道开放前，仍须单独完成适用许可、覆盖范围、Android 字段和使用频率核对；
这不属于通过修改 `approved`、更换测试身份或放宽响应校验就能完成的步骤。
