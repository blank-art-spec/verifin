## Android 手动验收

使用正式入口及真实 Controller/SQLite，优先独立 diagnostic applicationId 隔离验证；不能以独立演示页或桌面 widget 测试代替。安装前记录包名、设备序列号、提交、构建参数和现有数据备份。覆盖安装保留数据，禁止卸载或清除用户数据。构建/运行仅在后续明确执行验证的任务中手动开展。

| 编号 | 操作 | 预期 |
| --- | --- | --- |
| L01 | 用含日常、名为“投资账本”和证券持仓的旧数据库升级 | 全部显示普通账本，账户/事件/金额/偏好保留，不自动更名或改类型 |
| L02 | 新建账本，查看默认类型；选择投资和本位币后取消，再重新打开 | 默认普通，取消无新增；重开不遗留未提交类型 |
| L03 | 保存新投资账本后重启应用 | 类型仍投资，账本可访问，不自动生成证券账户或联网 |
| L04 | 普通改投资，投资再改普通 | 后续通用手动新增路径随类型变化，全部旧数据保留；改类型不改变币种 |
| L05 | 模拟类型保存失败、创建成功但指针切换失败 | 反馈准确，已保存状态可解释，重试不重复创建账本 |

| A05 | 新建证券账户并设置期初现金，分别取消和模拟聚合保存失败，再重试；覆盖已有主账户下新增币种 | 成功后直接使用证券页；取消/失败不遗留半套实体，不删除原有主账户；重试不重复创建同币种子账户 |
| A06 | 证券页点击新增；持仓内买卖；主账户顶部点击“＋” | 分别预填账户、预填证券/方向、仍新增币种；普通账户新增仍普通记账 |
| A07 | 查看普通现金/银行卡、银行主账户、信用账户 | 保留余额/趋势/流水或信用专属内容，无证券区域和错误额度入口 |

## 金额与隐私保护

- 关闭联网或使用注入的固定行情比较改动前后数据，避免实时价格变化掩盖问题。使用当前样例 JSON 和共享断言作为金额依据，不复制已过时的静态截图价格。
- 更改类型、切换页签、查看/编辑基本信息前后，对比账户、普通交易、投资组合、份额、总成本、现金、净在途、冻结和历史依据；除了明确保存的目标字段/事件，其余应一致。
- 股票、期权、基金各至少执行新增、编辑、取消、保存失败与重启；期权乘数与交割、基金起算与确认不借此次交互修改重新计算。
- 保留两个证券主账户的三币种隔离，同为 GOOG 的两份持仓不合并；一个账户操作不改变其他账户的计时、草稿或记录。
- 类型选择不发网络请求。已有行情授权、五分钟自动周期、逐账户计时、手动刷新和后台停止规则保持，未批准来源仍不可用。
- 截图、数据库和日志证据只存本地忽略的验证目录，避免提交实际用户账目。日志不包含备注、完整交易或密钥。
