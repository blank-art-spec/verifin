# 香港基金金额录入、确认与收益起算

2026-10-28 当前实现。公开净值来源及 Android 既有验证见[招商基金研究](cms-fund-api-research.md)。
本轮为离线业务开发，不编译 APK，不启动模拟器；新增表单的 Android 手动验收仍须完成。

## 两个入口

证券币种账户的操作区增加「基金操作」，提供「按金额买入」与「录入已有持仓」；香港基金卡也可进入。
目前支持账户内同币种香港基金，美元账户可显式选择招商美元货币市场基金 B 类 `HK0001039582`。
不会代建美元账户，不按名称猜证券类型；其他市场沿用原手工交易流程。

- 按金额买入：录入总扣款、其中费用和参考净值，预览份额。可以先保存未付款申请，稍后补实际扣款。
  未确认时净值只是估算，公开接口不会确认私人申购。收到券商结果后单独录入确认净值日、确认时刻、
  收益起算日和份额。允许实际份额覆盖推算值，并保留份额是否推算的标记。
- 录入已有持仓：录入券商显示的实际份额、总成本、对应净值及实际核对时刻，自动计算
  「市值＝实际份额 × 净值」和「未实现盈亏＝市值 − 总成本」，不再手填浮盈或由浮盈反推份额。
  核对基准替换该基金此时的数量及成本，不重复扣现金、不补造过去买入或收入。
  同 ID 编辑原基准，新 ID 创建后续核对基准，后续交易继续重放；不能放回日初后再次叠加当天买入。

以 **109.8290 USD/份** 为固定计算示例（不代表当前行情）：

| 输入 | 计算 | 结果 |
| --- | --- | --- |
| 新申购 1401.31 USD，费用零 | 1401.31 ÷ 109.8290 | 参考份额 12.75901629 |
| 已有实际份额 12.77，总成本 1401.31 USD | 12.77 × 109.8290＝1402.51633，市值按 USD 精度舍入后减总成本 | 市值 1402.52 USD，未实现盈亏 +1.21 USD |

金额按币种最小单位校验，量价采用八位定点数。总扣款包含费用，份额按净申购额计算；量价乘积
残差单独展示，不改写实际现金或成本。新申购的确认份额可覆盖估算并保留推算标记；
已有持仓的实际份额是输入事实，市值按币种现金精度舍入后减总成本，自动得到正或负的未实现盈亏。
`calculateFundOpeningByQuantity` 返回 `FundHoldingAmountResult`，与申购金额反推算法分开。

旧版 `reportedUnrealized` 字段和 `calculateFundOpeningByUnrealized` / `FundOpeningAmountResult`
仍保留用于旧账目、备份及历史计算兼容，但不再提供新的浮盈录入入口，不删除或重算原有账目事实。
编辑旧已有持仓时沿用其已存份额，不再用旧报告浮盈反推一次；未编辑的历史推算来源标记仍按原记录恢复。
显式编辑时，份额数值未变则保留其原推算标记；份额、成本、净值及核对时刻均未变才沿用旧报告浮盈。
用户改变基准依据后不再沿用旧浮盈证据，避免旧报数约束新成本；不会生成新的报告浮盈字段。

## 分阶段资产

| 事实 | 现金 | 在途资产 | 新份额 |
| --- | --- | --- | --- |
| 申请但未付款 | 不变 | 0 | 不增加 |
| 实际扣款 | 扣总款 | 总款减已明确费用 | 不增加 |
| 确认但尚未起算 | 不再扣款 | 继续保留 | 不增加 |
| 到该笔收益起算日 | 不变 | 转出该笔净款 | 加确认份额 |
| 取消但未退款 | 不变 | 保留待退资产 | 不增加 |
| 实际退款到账 | 加实际退款 | 结清该笔 | 不增加 |

申请、扣款、确认和退款为真实时刻，拒绝未来的「已发生」事实；预计确认日只作提示。
净值日与收益起算日分别保存香港纯日期，不依赖设备时区，不固定假设 T+1/T+2。
起算日以香港日初生效，同日付款更晚时不早于付款时刻。券商回执可以晚于经济起算日，补录后
历史按实际起算重算。各笔申购独立起算，新申购等待期间不暂停已有份额的收益。

实际付款一经保存不能通过普通编辑撤回或改总额；可补正费用分配。未扣款申请可删除，已付申请
保留资金依据，单独录入取消和实际退款。确认后通过卖出处理退出。本功能仅记录事实，不向券商
发出真实交易指令；重新读取时按时点推导状态，不增加后台自动确认或到账任务。

## 收益与历史

每个实际公布净值日，以香港日日末重放：

`区间参考收益 = 本期(市值 + 在途) − 上期(市值 + 在途) + 区间该基金实际现金腿`

付款、起算和退款只是资产形式变化，本金不会被当成收益。费用、实际退款差额、卖出和现金分红
沿用精确资金事实。跨已有持仓基准的区间收益未知，之后恢复；累计参考盈亏按最新基准及其后
交易计算，包含按基准份额、净值及总成本算出的基准盈亏。没有更早事实时，不补造开户日至基准日的持仓历史。

账户资产包括正现金、多头市值和在途款；负现金、空头义务单列负债，冻结额不重复扣除。
历史计算显式传截点，不因今天已经起算而删除过去的在途资产。快照摘要只含该时点经济事实，
后来补录未来确认不无故作废此前在途依据；回填更早起算或补正费用会影响对应历史。
现金核对用稳定资金腿 ID 对同刻扣款/退款去重。

只按来源公布日计算，不补造周末净值或将跨发布日区间称为单日到账收益。该接口没有万份收益、
七日年化，不将净值增长与年利率重复累加；其他证券缺同日价格时，完整账户历史资产仍未知。
参考结果不生成普通收入或自动权威资产快照。

## 持久化与验收

`FundSubscription`、确认信息及关联 `fundAcquire`/`fundHoldingBaseline` 保存在投资聚合。
SQLite 仍为 v28 文本载荷；完整备份为 JSON v14，旧 v1–v13 缺字段兼容，没有申购的旧聚合
和默认事件保持原 JSON 形状。公开净值历史仍为设备缓存、不进备份；账户/账本删除及初始化
沿用聚合清理边界。

手动验收使用隔离测试实例：

1. 打开 USD 证券账户的两个入口，输入 1401.31，未付款时检查现金和份额不变。
2. 补实际扣款，检查现金减少、在途净款增加；分别录入确认时刻、净值日及未来起算日。
3. 起算后重开应用，检查在途转份额、现金不二次扣减；等待期间旧份额继续估值，本金不计收益。
4. 录入实际份额 12.77、总成本 1401.31 和固定净值 109.8290，核对自动市值 1402.52、未实现盈亏 +1.21、现金不变及今天已有买入不重复叠加；把成本改为 1500 时自动显示未实现亏损 −97.48。检查旧已有持仓编辑保留原份额且没有浮盈输入框。
5. 检查取消、实际部分/零额退款、同刻现金核对、原基准编辑及后续新基准。
6. 冷启动、v14 恢复、旧 v13 模板恢复后核对金额、独立日期和推算标记；窄屏/大字号保存可达。
