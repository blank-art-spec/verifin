# 基金金额录入、确认与收益起算

2026-11-08：基金资料改为通用 ISIN 查询及显式核对确认；2026-11-06 手动录入与
原 2026-10-29 金额、确认和收益规则保持。
公开净值来源、2026 年 4 月官方交易规则及 Android 既有验证见[招商基金研究](cms-fund-api-research.md)。
开发机匿名请求不替代 Android 运行验证；本轮最终验证状态在下方记录。

## 两个入口

证券币种账户的操作区提供「基金操作」，包含「按金额买入」与「录入已有持仓」；符合范围的基金卡也可进入。
目前支持账户内同币种的香港及内地基金，美元账户继续提供招商美元货币市场基金 B 类 `HK0001039582`。
不会代建币种账户，不按名称猜证券类型；美国基金仍沿用原手工份额交易入口，不能套用本流程的 UTC+8 日期。

## 手动新增资料与 ISIN 查询（2026-11-08）

两个金额入口均提供「手动新增基金」，填写基金代码、名称及香港/内地市场，币种固定为当前真实账户币种。
已有同市场、同币种、忽略代码大小写的基金复用原身份；本地候选只来自当前账本的同币种基金。
资料页复用本地 `InvestmentSecurityAutocomplete`、`EntryEditorSurface` 与统一返回保护，只返回 `StockSecurity` 草稿；
联网候选使用独立卡片核对，避免与已保存的本地基金身份混淆。
返回金额表单后可以继续修改新资料；只有最终保存申购或已有持仓基准时，才与该笔业务一起持久化。
取消资料页、丢弃父表单、切换交易页签均不会预先创建基金、增加份额或扣款。

`supportsFundAmountWorkflow` 统一限制明确的基金品种、无期权规格及香港/内地市场；Controller 另行校验账户币种。
香港与内地日期均采用 UTC+8，因此复用现有纯日期边界；没有为美国基金推断时区，也没有改动已有起算算法。
其他基金的实际份额、总成本、申购确认、收益起算日与手填单位净值仍须按券商记录核对。
万份收益、七日年化、累计收益不能填入单位净值；本次不增加自动分红或每日收益结转。

输入完整 ISIN 后可主动点击「按代码联网查基金」。查询先核对十二位字母数字形状及 Luhn 校验位，
不限制基金公司或 ISIN 国家前缀；内地六位基金代码仍可手填，不当作 ISIN 发送。输入、打开页面及本地候选匹配不会联网。
查询得到的 `FundIdentityCandidate` 卡片展示来源原名、ISIN、份额类别、币种、来源名称及 URL，
用户核对并显式确认后才填入代码与名称；市场保持用户选择，不按代码前缀或基金投资地域猜测。
币种不匹配仍显示来源实际资料，但禁止填入当前账户；份额类别或币种缺失时保留未知，不能确认采用。
无结果、断网或来源变动时仍可手工录入。查询、确认或取消都不直接创建证券、持仓、申购或交易。
查询期间改代码、名称或市场，以及换账本、账户失效或离页，旧响应不能覆盖新草稿或抢占当前页面。

### 通用目录与补充来源

主来源按裸 ISIN 匿名请求 `https://www.laohu8.com/FUND/{ISIN}`，无需币种参数或账号。
读取公开页面 `textarea#__APP_DATA__` 中的身份 JSON，`fundInfo.code` 必须精确命中输入，
可直接采用的 `fundInfo.symbol` 必须是同一 ISIN 加明确币种后缀；缺少币种时保留未知，
错配的非空份额标识拒绝。份额类别仅从原名中的明确标记提取，普通币种缩写或引号词不充当类别。
不把报价显示币种、基金基础币种或账户币种替代该份额的来源币种，也不执行页面脚本。
这是跨基金公司的第三方资料目录，不是基金官方认证；不限制公司不等于保证全部基金均被收录。

SQLite v30 / JSON v18 结构不变，保存后的基金身份及业务沿用原持久化、冷启动和备份恢复路径；
候选的来源字段只保留于本次查询，不新增备份或持久化字段。

## 金额录入与确认

以下继续说明既有金额、确认与收益规则；本次身份查询没有改变这些规则。

- 按金额买入：录入总扣款、其中费用和参考净值，预览份额。可以先保存未付款申请，稍后补实际扣款。
  未确认时净值只是估算，公开接口不会确认私人申购。收到券商结果后单独录入确认净值日、确认时刻、
  收益规则和份额。招商美元 B 类新确认默认以实际成交净值日形成基准，不另填固定起息日；
  其他基金和旧记录沿用独立收益起算日。允许实际份额覆盖推算值，并保留份额是否推算的标记。
- 录入已有持仓：录入券商显示的实际份额、总成本、对应净值及实际核对时刻，自动计算
  「市值＝实际份额 × 净值」和「未实现盈亏＝市值 − 总成本」，不再手填浮盈或由浮盈反推份额。
  核对基准替换该基金此时的数量及成本，不重复扣现金、不补造过去买入或收入。
  同 ID 编辑原基准，新 ID 创建后续核对基准，后续交易继续重放；不能放回日初后再次叠加当天买入。

以 **109.8290 USD/份** 为固定计算示例（不代表当前行情）：

| 输入 | 计算 | 结果 |
| --- | --- | --- |
| 新申购 1401.31 USD，费用零 | 1401.31 ÷ 109.8290 | 参考份额 12.75901629 |
| 已有实际份额 12.77，总成本 1401.31 USD | 12.77 × 109.8290＝1402.51633，市值按 USD 精度舍入后减总成本 | 市值 1402.52 USD，未实现盈亏 +1.21 USD |

金额按币种最小单位校验，量价采用八位定点数。总扣款包含费用，份额按净申购额计算；量价乘积
残差单独展示，不改写实际现金或成本。新申购的确认份额可覆盖估算并保留推算标记；
已有持仓的实际份额是输入事实，市值按币种现金精度舍入后减总成本，自动得到正或负的未实现盈亏。
`calculateFundOpeningByQuantity` 返回 `FundHoldingAmountResult`，与申购金额反推算法分开。

旧版 `reportedUnrealized` 字段和 `calculateFundOpeningByUnrealized` / `FundOpeningAmountResult`
仍保留用于旧账目、备份及历史计算兼容，但不再提供新的浮盈录入入口，不删除或重算原有账目事实。
编辑旧已有持仓时沿用其已存份额，不再用旧报告浮盈反推一次；未编辑的历史推算来源标记仍按原记录恢复。
显式编辑时，份额数值未变则保留其原推算标记；份额、成本、净值及核对时刻均未变才沿用旧报告浮盈。
用户改变基准依据后不再沿用旧浮盈证据，避免旧报数约束新成本；不会生成新的报告浮盈字段。

## 已核实的招商美元 B 类收益归属

官方 2026-04 说明书第 19 页及 USD 附录第 136–137 页规定，按实际被接纳交易日的估值点
净值发行单位，截止后申请顺延，分销商可以更早截止。没有找到独立固定 T+1/T+2 起息条款。
据此采用实际成交净值为该笔基准，后续净值差归相应公布区间；确认回执晚到不改变归属。
这是由定价条款推导的记账口径，不代表已经核验所有券商的界面显示日和内部舍入。

`FundSubscriptionConfirmation.accrualRule` 显式保存口径：

- `dealNavDate` 仅支持真实 HK/USD 基金 `HK0001039582`。成交净值日形成基准，不享有
  之前净值到成交净值的变化；日级持仓以香港日日末截点生效，下一实际公布净值点计其后变动。
  日日末只是日报截点，不能当成官方真实收市钟点。原兼容 `earningStartDate` 保存为同一净值日，
  不再独立控制此规则。暂不支持扣款晚于成交净值日的先获份额后欠款模型，须核对记录后处理。
- `explicitStartDate` 沿用原独立收益起算日日初规则，且不早于付款时刻。缺字段的旧 v14
  及更早备份继续按此解释，事件和旧历史依据不静默改写。旧 CMS 订单可在确认页明确选择新规则
  重新核对，替换同一确认事件；不重复扣现金，也不重设成本抹去真实盈亏。

重核不能跨已保存的持仓基准改变该笔申购是否已被基准覆盖；同一净值日内先核对、后按日末
增加份额也无法证明核对是否包含申购，故原子拒绝并保留旧事实。日末同刻按稳定事件序号校验，
不能通过时间相同绕过。应先核对实际基准范围，避免数量、成本在现金不变时翻倍或漏算。

固定示例：10 份以 T 日净值 100 成交，T+1 净值 101，T+2 净值 102，回执 T+3 才收到。
新规则下 T 日只形成基准（无费用及结算差额时收益 0），后两区间分别为 +10、+10，
不将 +20 集中计在回执日。若公开来源只提供 T+2 的第一个观察点，累计盈亏可知为 +20，
该点的区间收益仍未知；不能把回执上的成交价伪造为新增公开历史净值点。

| 确认但未到规则生效截点 | 不再扣款 | 继续保留 | 不增加 |
| 到该笔规则生效截点 | 不变 | 转出该笔净款 | 加确认份额 |
| 取消但未退款 | 不变 | 保留待退资产 | 不增加 |
| 实际退款到账 | 加实际退款 | 结清该笔 | 不增加 |

申请、扣款、确认和退款为真实时刻，拒绝未来的「已发生」事实；预计确认日只作提示。
净值日和旧规则收益起算日保存香港纯日期，不依赖设备时区，不固定假设 T+1/T+2。
旧规则起算日以香港日初生效，同日付款更晚时不早于付款时刻；新规则以成交净值日日末形成
日级基准。券商回执可以晚于经济日期，补录后历史按已保存规则重算；各笔申购独立，新申购
等待期间不暂停已有份额的收益。

实际付款一经保存不能通过普通编辑撤回或改总额；可补正费用分配。未扣款申请可删除，已付申请
保留资金依据，单独录入取消和实际退款。确认后通过卖出处理退出。本功能仅记录事实，不向券商
发出真实交易指令；重新读取时按时点推导状态，不增加后台自动确认或到账任务。

2026-11-05 误录纠错例外：持仓卡新增“清除持仓”，须确认删除范围与现金前后值，可将该账户
这一基金的全部期初、份额交易、持仓基准及申购事实一并删除，申购含实际付款、确认和退款。
这不改变上述单笔申请/付款编辑限制；真实取消仍使用取消及退款流程。清除时同时移除确认事件
和同刻资金腿引用，不能留下在途款或未来再起算的份额；普通资金流水和已核对现金锚点保持。
跨账户转移或删除后其他资金事实不合法时拒绝整次清除。详见[证券删除口径](securities-stage02-implementation.md)。

## 收益与历史

每个实际公布净值日，以香港日日末重放：

`区间参考收益 = 本期(市值 + 在途) − 上期(市值 + 在途) + 区间该基金实际现金腿`

付款、起算和退款中的本金只是资产形式变化，不会被当成收益。费用、实际退款差额、卖出和现金分红
沿用精确资金事实。区间收益保留完整净盈亏，另以 `subscriptionAdjustment` 单列其中申购费用和
结算差额：实际付款列负费用，确认时按稳定事件顺序计算新增份额的合并市值增量相对净申购款
的差额，退款时列实退额相对净款的差额。合并舍入与完整市值一致，避免逐笔半分舍入后加总
与账户相差一分；新规则成交日有公开净值时也纳入发行价相对公开净值的已知差额，缺该日来源
点时仅拆出已知成交价/份额尾差，不补造未知发行价差。此分项已包含在区间净盈亏中，不重复
加减，也不将份额截位损失叫正常净值增长。
跨已有持仓基准的区间收益未知，之后恢复；累计参考盈亏按最新基准及其后
交易计算，包含按基准份额、净值及总成本算出的基准盈亏。没有更早事实时，不补造开户日至基准日的持仓历史。

账户资产包括正现金、多头市值和在途款；负现金、空头义务单列负债，冻结额不重复扣除。
历史计算显式传截点，不因今天已经起算而删除过去的在途资产。快照摘要只含该时点经济事实，
后来补录未来确认不无故作废此前在途依据；回填更早起算或补正费用会影响对应历史。
现金核对用稳定资金腿 ID 对同刻扣款/退款去重。

每点携带 `profitFromDate` 并展示前后实际净值日期。只按来源公布日计算，不补造周末净值或
将跨发布日区间称为单日到账收益，不按年化利率分摊周末。该接口没有万份收益、
七日年化，不将净值增长与年利率重复累加；其他证券缺同日价格时，完整账户历史资产仍未知。
参考结果不生成普通收入或自动权威资产快照。
