# 证券双标的测试模板

更新日期：2026-10-25。文件：[verifin-sample-backup.json](verifin-sample-backup.json)，格式 JSON v12。

## 账户结构

模板保留原有日常、旅行账本，并在“投资账本”中使用以下结构：

```text
投资账本（本币 CNY）
└─ 投资账户（证券总账户，展示币种 CNY）
   ├─ 投资账户.CNY：零余额，无持仓
   ├─ 投资账户.USD：GOOG 与 AVGO 的全部买卖、现金和持仓
   └─ 投资账户.HKD：零余额，无持仓
```

总账户 ID 为 `parent_investment`，三个真实子账户 ID 分别为
`acc_investment_cny`、`acc_investment_usd`、`acc_investment_hkd`。
证券总账户只汇总，不直接保存证券交易；两只股票共用 USD 子账户的一份
`investmentPortfolios` 聚合，不按股票另建账户，也不重复建立 USD 子账户。

## 手动验收

1. 在独立 diagnostic 测试应用中，通过现有备份恢复流程预览并恢复模板；
   使用隔离实例，因为完整备份恢复会替换该实例的账目。模板保持默认选中“日常账本”。
2. 切换到“投资账本”，在资产页确认只有一个证券总账户，展开后为 CNY、USD、HKD。
3. 进入 USD 子账户的证券持仓，检查两只各 6 股、四笔测试买卖和上表金额。
4. 返回总账户，核对 72,772 CNY；进入 CNY、HKD，确认二者现金均为零。
5. 关闭并重新打开应用，再导出并恢复到另一个隔离实例，核对账户层级、事件、
   手填价和金额保持一致。测试文件修改不会自动更新已安装应用的数据。

旧模拟器准备入口 `test/investment_emulator_seed_test.dart` 仍默认跳过。
显式运行时，新模板已有 10,000 期初现金则不再入金；旧版零期初保留原有银行转账，
再按稳定事件 ID 保存双标的买卖，避免重复入金或重复追加同一事件。
应用编译由用户手动执行，本次不自动构建、安装或更新设备数据。

回归检查复用同一套双标的断言，覆盖样例实际导入、导出后恢复和 SQLite 新控制器重读。
独立场景的完整证券功能验收继续参照[证券验收操作](securities-trading-acceptance.md)。
