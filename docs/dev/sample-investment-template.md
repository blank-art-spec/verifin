# 证券三地测试模板

更新日期：2026-10-27。文件：[verifin-sample-backup.json](verifin-sample-backup.json)，格式 JSON v12。

## 账户结构

模板保留原有日常、旅行账本，并在“投资账本”中使用以下结构：

```text
投资账本（本币 CNY）
└─ 投资账户（证券总账户，展示币种 CNY）
   ├─ 投资账户.CNY：中远海能 A 股 600026
   ├─ 投资账户.USD：博通 AVGO 与谷歌 GOOG
   └─ 投资账户.HKD：腾讯控股 00700、示例认购多头及认沽空头
```

总账户 ID 为 `parent_investment`，三个真实子账户 ID 分别为
`acc_investment_cny`、`acc_investment_usd`、`acc_investment_hkd`。
总账户只汇总；每个真实币种账户各有一份 `investmentPortfolios` 聚合，
同币种的股票与期权共用现金，不按证券另建账户。

- 腾讯控股使用港元柜台 **00700 / HKD**，不使用人民币柜台 80700。两者区别见
  [腾讯双柜台公告](https://www1.hkexnews.hk/listedco/listconews/sehk/2023/0609/2023060900580.pdf)。
- [港交所股票期权资料](https://www.hkex.com.hk/Products/Listed-Derivatives/Single-Stock/Stock-Options?sc_lang=en)
  列示腾讯标准股票期权代码 TCH、合约单位 100 股；权利金按港元每股报价，采用美式及实物交割。
  模板使用 **TEST-TCH-CALL-20261230-440** 与 **TEST-TCH-PUT-20261230-380**，
  明确标为本地虚构验收合约，**不是港交所真实挂牌代码或可交易合约**。
  到期日、行权价、价格、费用和冻结额均是测试输入，不证明对应真实合约存在。
  当前腾讯参考行情适配器只支持股票；这两份合约不发送联网请求，持续使用手填价，
  页面提示不支持期权不代表刚刚发生网络获取失败。
- 中远海能使用 **600026 / 上交所 A 股 / CNY**，不与港股 01138 混淆；
  身份见[上交所公司资料](https://www.sse.com.cn/assortment/stock/list/info/company/index.shtml?COMPANY_CODE=600026)。
- 原 USD 的 GOOG 与 AVGO 不变；GOOG 不与 GOOGL 混用。
- 全部价格、资金和汇率均为固定验收输入，不代表真实历史成交、市场现价或券商规则。
  三个币种均只使用手填参考价，行情覆盖列表为空；新增模板不代表三地自动行情已经准入。

## 手动验收

1. 在隔离 diagnostic 测试实例中，通过既有备份恢复预览并恢复模板；完整恢复会替换
   该实例的账目，因此不要覆盖有需保留数据的实例。模板默认仍选中“日常账本”。
2. 切换到“投资账本”，确认只有一个证券总账户，展开后为 CNY、USD、HKD。
3. USD 核对原两只股票各 6 股；CNY 核对 600026 的 600 股；HKD 核对 00700 的
   100 股、TEST 认购 1 张多头、TEST 认沽 1 张空头、六笔事件及上表金额。
4. HKD 核对现金、总资产、负债、净值和冻结额分别显示，冻结不重复扣减。
   返回总账户核对净值 189,910 CNY。
5. 关闭重开，再导出并恢复到另一个隔离实例，核对账户层级、事件、合约规格、手填价、
   保证金及金额保持一致。只浏览页面不得改写成交、价格或现金。

`test/investment_emulator_seed_test.dart` 默认跳过；仅显式指定
`build/validation/` 内已有模拟器数据库副本时准备数据。设备准备应先备份，保留已有
记录和原 USD 资金来源，用稳定事件 ID 避免重复注资/追加，不直接修改正式应用数据。
本次构建与运行按用户 2026-10-27 的明确指令执行，不建立自动构建任务；
后续仍遵循手动构建约定。
