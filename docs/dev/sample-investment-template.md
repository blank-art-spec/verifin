# 证券三地双账户测试模板

更新日期：2026-10-27。文件：[verifin-sample-backup.json](verifin-sample-backup.json)，格式 JSON v12。

## 账户结构

模板保留原有日常、旅行账本，并在“投资账本”中使用以下结构：

```text
投资账本（本币 CNY）
├─ 投资账户（证券总账户，展示币种 CNY）
│  ├─ 投资账户.CNY：中远海能 A 股 600026
│  ├─ 投资账户.USD：博通 AVGO 与谷歌 GOOG
│  └─ 投资账户.HKD：腾讯控股 00700、示例认购多头及认沽空头
└─ 投资账户二（证券总账户，展示币种 CNY）
   ├─ 投资账户二.CNY：国电电力 A 股 600795
   ├─ 投资账户二.USD：谷歌 GOOG
   └─ 投资账户二.HKD：零现金、空持仓
```

原总账户 ID 为 `parent_investment`，三个真实子账户 ID 分别为
`acc_investment_cny`、`acc_investment_usd`、`acc_investment_hkd`。
第二个总账户 ID 为 `credit-account-acc_investment_2_cny`，由首个 CNY 子账户通过
生产账户命令派生，三个子账户 ID 分别为
`acc_investment_2_cny`、`acc_investment_2_usd`、`acc_investment_2_hkd`。
总账户只汇总；六个真实币种账户各有一份 `investmentPortfolios` 聚合，
同币种的股票与期权共用本账户现金，不按证券另建账户。
两个 USD 子账户各自持有 GOOG，现金、数量、成本、事件和手填价独立，不合并为一份持仓。

## 手动验收

1. 在隔离 diagnostic 测试实例中，通过既有备份恢复预览并恢复模板；完整恢复会替换
   该实例的账目，因此不要覆盖有需保留数据的实例。模板默认仍选中“日常账本”。
2. 切换到“投资账本”，确认有“投资账户”“投资账户二”两个证券总账户，
   各自展开后均为 CNY、USD、HKD，六个子账户分别归属正确的父账户。
3. USD 核对原两只股票各 6 股；CNY 核对 600026 的 600 股；HKD 核对 00700 的
   100 股、TEST 认购 1 张多头、TEST 认沽 1 张空头、六笔事件及上表金额。
4. HKD 核对现金、总资产、负债、净值和冻结额分别显示，冻结不重复扣减。
   返回原总账户核对净值 189,910 CNY。
5. 第二个总账户核对净值 90,838 CNY；USD 只持有 GOOG 5 股，CNY 只持有
   国电电力 1,000 股，HKD 为零现金、空持仓。核对两组 GOOG 的数量、成本及手填价互不覆盖，
   投资账本净值为 280,748 CNY。
6. 关闭重开，再导出并恢复到另一个隔离实例，核对账户层级、事件、合约规格、手填价、
   保证金及金额保持一致。只浏览页面不得改写成交、价格或现金。

`test/investment_emulator_seed_test.dart` 默认跳过；仅显式指定
`build/validation/` 内已有模拟器数据库副本时准备数据。设备准备应先备份，保留已有
记录和原 USD 资金来源，用稳定事件 ID 避免重复注资/追加，不直接修改正式应用数据。
本次构建与运行按用户 2026-10-27 的明确指令执行，不建立自动构建任务；
后续仍遵循手动构建约定。
