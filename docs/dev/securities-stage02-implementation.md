# 股票投资阶段 0–2：当前实现与验收

日期：2026-10-23。分支：`codex/securities-trading-quotes-20261023`。总体范围及后续任务仍见 [完整方案](securities-trading-plan.md)，完整用例见 [验收操作](securities-trading-acceptance.md)。股票账务已实现，阶段 0 的公开来源门禁仍有缺口；实际验证结果见下方完成记录。

## 1. 本轮范围

- 复用投资账户及 CNY / USD / HKD 子账户，用户从账户详情进入“股票投资”，显式确认期初现金与可选持仓。原账户余额不自动解释为现金；启用可以取消。
- 股票/ETF 手工建档保留美股、A 股、港股市场与原始代码；操作落到真实币种账户，按币种结算，不自动换汇。博通 AVGO 为本轮测试标的。
- 买入、卖出、卖空、回补、股息及税费、费用、拆股/合股、同币种持仓转移；支持编辑/删除普通投资事件、未知期初成本补齐及手填参考价。融资必须在启用时明确确认。
- 账户现金、持仓净值、已实现/未实现盈亏分开。父子账户和当前资产总额使用同一个 `accountAssetValue`；`accountBalance` 继续只表示现金。买卖不变成普通消费/收入，入金沿用真实双向转账。
- “博通行情验证”由用户点击后才查询 Yahoo 股票及 Nasdaq 有界期权链；只展示公开字段，不自动更新参考价，不创建期权持仓，无后台轮询。
- 期权开平仓/保证金/交割、联网自动估值、完整历史净值和三地自动行情覆盖属于后续阶段。本轮不能据股票记账或公开字段读取结果宣称这些功能已完成。

## 2. 存储与精度

SQLite v28 新增 `investment_portfolios(id, book_id, payload)` 及账本索引，历史迁移不回改。每个币种账户一份不可变 `InvestmentPortfolio`，包含期初现金、证券定义、期初多空持仓、稳定序号事件、持续手填价和现金锚点的同刻已包含 ID。SQLite 行映射仍集中在 `ledger_repository.dart`。

与最初多张投资表的提案相比，当前股票阶段采用**单账户聚合文本行**：同一事件隐含的现金腿、成本和数量在一次保存中共同变更；现金腿由独立事件重放，绝不再生成 `LedgerEntry`。两端持仓转移在同一个投资集合事务保存，失败完整回滚。这样可先用较小迁移实现严格原子性；后续有性能证据时再分拆事件表，不能维护第二份独立可写余额。

`InvestmentDecimal` 用 BigInt 和八位定点数保存数量/价格。量价乘积直接按币种 minor unit 舍入，成本按比例分摊，最后一笔释放全部余数；double 仅用于既有格式化/现金接口边界。禁止 NaN、指数、超范围和超过八位小数的输入。未知成本保留 null，盈亏显示未知；当前手工估值阶段要求非空持仓有明确参考价。

事件按业务时间及稳定序号重放。编辑后若导致后续超量平仓或未确认融资的历史负现金，拒绝整个草稿。持仓转移目前仅允许追加到两端历史末尾，成对保留成本；不支持单边编辑/删除或回填历史转移。账户仍有转移批次时，拒绝只删除其中一个账户，避免另一端失去成本依据。

现金核对复用 `BalanceAnchor`，投资聚合保存同刻已包含的 `entry:` / `stock:` ID。现金锚点与聚合在一个事务保存；补录同刻但未包含的事件仍计入，已有事件不重复。现金核对不截断持仓重放，也不生成伪造消费。

投资启用、账户草稿保存、账户删除及现金锚点统一进入现有串行命令队列，避免同时操作留下悬空聚合或把启用后的投资账户改成不支持的类型。并发用例中两项在修复前失败，三项在修复后均通过。普通流水/锚点现有 SQLite 时间精度为毫秒，现金边界按相同精度比较；投资事件的稳定序号仍保留原始先后。

完整备份 JSON 升 v10，新增 `data.investmentPortfolios`；v1–v9 缺键按空恢复，旧账户不自动启用。期初、成交、手填价和锚点边界进备份；单次行情响应、请求状态不进备份。当时的 v10 样例三币种投资子账户仍为零，没有预置博通成交；2026-10-27 的当前 v12 模板保留 USD 的 GOOG + AVGO，新增 CNY 中远海能及 HKD 腾讯股票和本地示例期权，见[模板说明](sample-investment-template.md)。删除账户/账本和初始化会通过既有全量事务清理相应聚合。

## 3. 行情来源的真实结论

2026-10-23 的桌面公开请求：Yahoo AVGO chart 返回 HTTP 200、USD 股票字段及源时间；Yahoo options 返回 401，未绕过或反复重试；Nasdaq 有界期权链返回 HTTP 200。提供未来起止日期可取得未到期配对，例如响应中的 2026-12-04、行权价 325 两侧字段，按来源给出的到期日/行权价映射为 `AVGO261204C00325000` / `AVGO261204P00325000`。

这只是一次来源可行性记录，不是当前报价承诺。Nasdaq 此响应没有各期权字段的有效报价时间、权利金乘数与交割规格，因此页面明确标记未知；股票源时间与抓取时间分开。该来源仍不能直接用于后续期权自动估值或正式合约确认。Yahoo/yfinance 的个人用途提示和各数据源发布条件仍需独立核对；开源代码许可不替代数据使用条件。

生产验证客户端只发送 AVGO、日期及分页参数，固定 HTTPS 主机、不跟随重定向、不带用户凭证，单次 15 秒、512 KiB 上限；字段/身份/时间不合法或访问失败就显示不可用。构造客户端、打开持仓和冷启动均不联网。没有向用户提供“已支持全部实时行情”的承诺。

同日 Android 实测先遇到模拟器 DNS 解析失败；使用本机实际 DNS 重新启动同一 AVD 后，用户触发的实际请求成功。21:30 CST 的页面显示 Yahoo AVGO 股票价格与源时间，以及 Nasdaq `AVGO261127C00320000` / `AVGO261127P00320000` 两侧公开字段。期权报价时间、乘数及交割规格仍未知，所以这证明当次手机直连可行，尚不满足完整来源/合约门禁，也不构成稳定可用性或发布承诺。网络失败、超时与字段异常已有不同的本地化提示，日志仅保留安全类别。

21:37 再次从安装后的应用查询成功，按当时响应接近标的价格的配对变为 `AVGO261127C00325000` / `AVGO261127P00325000`；没有固定返回某个测试合约。查询后数据库仍只有原两笔股票事件，手填价仍为 330。

测试仅保留 [最小公开字段 fixture](../../test/fixtures/investments/)，不在普通单元测试中请求网络；更多响应和现场证据留在被忽略的 `build/validation/avgo-p0/`。

### 用户手动复验

1. 在已运行的独立应用选择“投资账本”，进入“资产 → 投资账户”，核对 CNY / USD / HKD 及父账户总额。
2. 点 USD → 股票投资，核对第 4 节现金、数量、成本和盈亏；向下滚动查看两笔标为“验收示例”的买卖。
3. 点“记录股票交易”可新增或取消草稿；点已有记录可修改/删除。超量卖出、未确认融资的现金不足、破坏后续持仓的编辑会拒绝保存并保留草稿。
4. 股息/费用填总额；拆股填新旧股数比例，不在比例字段扣费用；需收费时另记费用事件。参考价只用于估值，修改后现金及真实成交不变。
5. 点顶部云图标进入“博通行情验证”，阅读联网说明后手动查询。网络不可用、超时、字段异常分别提示；未知报价时间不会显示为实时。此页不会修改手填价 330。
6. 关闭并重新启动应用，按第 1–2 步复查。测试数据按用户要求保留；期权记账、自动刷新与正式发版不在本次完成范围。
