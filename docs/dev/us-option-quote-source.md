# 美股期权参考行情接入

更新：2026-11-06。

## 来源选择与边界

股票继续使用腾讯，基金继续使用指定招商来源。美股期权改用 Alpaca 的
[Historical Trades API](https://docs.alpaca.markets/us/reference/optiontrades)，
固定请求 `https://data.alpaca.markets/v1beta1/options/trades`，不发送该接口未定义的 `feed` 参数。
该接口按完整合约代码返回历史成交的价格 `p`、实际时间 `t` 和成交条件 `c`。
依据[官方历史数据说明](https://forum.alpaca.markets/t/data-source-for-option-historical-bars/17704)，
免费 Basic 账户可查询 15 分钟以前的真实 OPRA 历史数据，无需订阅实时行情；仍须用户
自行注册并配置 Key ID 与 Secret Key。不自动注册、购买订阅或连接任何下单接口。
不回退为免费 indicative feed：官方说明其买卖报价经过修改，成交存在延迟，
不能将其展示为实际 OPRA 买卖价格。

复用原行情同步、手动刷新、前台五分钟自动刷新、逐证券采用与只读估值机制；
新增数据适配器不替换股票请求方式。构造适配器、打开设置或填写凭证都不自动
开启联网。应用无自有行情服务端；密钥只通过认证头发送给固定 Alpaca 主机。

录入页主动查询还会读取 Alpaca 的
[单一合约规格接口](https://docs.alpaca.markets/us/v1.4.2/reference/get-option-contract-symbol_or_id)
`GET /v2/options/contracts/{symbol_or_id}`，按完整合约代码获取明确的 `multiplier`。
[官方字段说明](https://docs.alpaca.markets/us/reference/get-options-contracts)将 `multiplier`
与实际交割数量 `size` 分开定义，不能用 `size` 代替权利金乘数，也不默认填 100。
本入口只在“查询合约与行情”时调用，普通持仓行情刷新不额外查询或改写规格。

来源标识改为 `Alpaca OPRA Delayed`，旧版 `Alpaca OPRA` 实时快照缓存不再用于当前
参考估值，也不以旧缓存的较新时间阻止延迟成交结果。凭证及用户的联网、自动刷新和
逐证券采用选择保留；现金、成本、交易、手填后备价和用户已保存的历史依据均不迁改。

以下调查仅是排除当前可用候选的证据，不是对全部供应方接口的断言：

- 原腾讯股票入口按 `usAVGO261204C00325000` 查询已确认存在的合约，HTTP 200，
  正文仅 `v_pv_none_match="1";`（21 字节）。不能直接把股票代码换成 OCC 代码；
  不能据此推论腾讯全部其他接口均不支持期权。
- Nasdaq 匿名 AVGO 期权链返回价格，但缺少对应报价字段的来源时间；不能把
  标的股票时间、HTTP 日期或抓取时刻当作期权价格时间。
- Cboe 延迟链包含合约和价格，但[官方报价页](https://www.cboe.com/delayed_quotes/avgo/quote_table)
  明确限制自动提取；未作为自动刷新来源接入。
- Tradier 有正式期权接口，但个人 token 可访问整个账户，公开应用另有合作认证要求；
  本轮不接入。Alpaca 也须用户遵守自身账户及数据权限，不将接口文档当作普遍使用许可。

## 配置与隔离

“参考行情 → 美股期权行情”录入 Key ID 和 Secret Key，保存后在本机加密保留，
重启应用自动恢复。Android 使用 Android Keystore 保护加密密钥，独立密文放在
`noBackupFilesDir/option_quote_credentials.v1`，不写 SharedPreferences、SQLite、报价缓存、账目备份或日志，
不增加第三方插件依赖。卸载或换机后须重新配置，不修改 SQLite/JSON 备份版本。
原生 `OptionQuoteCredentialStore.kt` 使用不可导出的 AES-256/GCM 密钥及随机 IV，
整对凭证通过 `AtomicFile` 原子更新；读失败不重建密钥或降级明文。清除删除密文及
临时文件；若存在旧版原子文件备份，先恢复到主文件再删除，后续删除失败仍保留有效凭证。
保留设备密钥，避免删除失败后使原数据不可读；现有 `allowBackup=false` 保持。
编辑页不回显旧凭证，填写两项才能替换，留空保持不变；取消不写入，只有安全存储
完成后才显示保存成功。读取失败显示明确错误，允许重新配置或主动清除，不把失败
当作未配置，也不自动删除旧密文。清除使用独立操作，成功后不再于重启恢复。
凭证属于设备配置，删除账户、账本或恢复账目不会清除；显式清除或卸载才删除。
更换或清除前取消旧请求结果，清除此来源的旧缓存；股票和基金缓存不清除。
缓存清理或安全存储失败不应用新凭证，输入留在页面供重试。网络失败只记录来源及数量，
不得记录认证头、请求原文或可能携带凭证的异常。

规格查询的模拟与真实环境凭证不互通：已知 `PK` 前缀固定访问
`paper-api.alpaca.markets`，已知 `AK` 前缀固定访问 `api.alpaca.markets`；前缀只用于
选择环境，不证明凭证有效。未知前缀不猜主机，保留手填；认证失败不换环境重试。
仅允许上述单一规格 GET 路径，不开放账户或下单接口，不跟随重定向。
成交查询继续固定访问 `data.alpaca.markets`，原凭证保存方式与行情行为保持不变。

## 身份、价格与估值

仅接 USD、美国市场、完整 OCC 合约代码；校对代码中的标的根、到期年月日、C/P
及千分之一单位行权价，与用户录入的公开合约资料完全一致。首版只接受可直接
匹配普通字母标的的合约；调整合约、类别股映射和 TEST 示例不猜代码，保留手填。
不向接口发送数量、成本、保证金、交割说明、账本账户或备注。

每批最多 20 个合约，整批共用 15 秒及累计 512 KiB 预算；固定 HTTPS 主机与路径，
不跟随重定向，401/403/429 不变更身份或转至别的服务器重试。每个合约独立请求，
每页及每合约请求前检查联网、前台和账本会话，用户撤销后不继续后续请求。
使用 `sort=desc` 和受控分页，避免接口按合约优先排序时只返回首个合约的成交。
合约请求当前串行执行，慢网下多合约可能耗尽整批 15 秒而刷新失败；实际吞吐与
Android 连通性仍须配置真实凭证后验证，离线测试不代表已通过此项验收。
请求明确指定 UTC 时间窗：截止为本批开始时间减 16 分钟（免费 15 分钟限制加一分钟
时钟裕量），起点为截止前 168 小时，覆盖普通周末及短假期；这是绝对时间窗口，
不是按设备时区计算七个日历日，也不是完整历史行情下载。
只采用此区间内正价格、真实时间且成交条件允许更新价格的最新有效成交；取消、迟报、
乱序、不更新价格及未知条件不用于估值。来源条件含义见
[官方期权聚合规则](https://docs.alpaca.markets/us/docs/market-data-faq#how-are-option-bars-aggregated)。

源 JSON 价格保留十进制文本，按准确合约键匹配响应；未知时间、错误日期、区间外时间
及无效价格不进入估值。报价只填 `last` / `lastAt`，不再用实时快照的双边中间价；
`delayMinutes: 15` 表示来源的最低延迟，实际成交可能更早。不能用抓取时间补齐成交时间，
乘数只在持仓估值中应用一次。窗口内无合格成交或分页预算耗尽时明确缺价，保留手填。

股票/期权的有效参考价距今超过 24 小时会在行情列表和持仓报价依据中提示。
提示不推断休市/停牌状态，不因周末将最近可用价自动作废；基金日净值不套用此阈值。
现金、持仓数量、成本、真实交易与手填后备价始终不因刷新而改写。

## 录入时查询合约与行情

期权交易与期初持仓表单提供“查询合约与行情”，只在用户主动点击后发起查询。
USD 美股账户中的标准完整代码沿用 `parseUsOptionSymbol` 解析标的、到期日、
认购／认沽及行权价，补充未手动修改的草稿身份；再查询标的股票名称，组合成可编辑
期权名称。该名称由应用生成，不是历史成交接口返回的券商合约名称。手填名称与已使用
的锁定身份不覆盖；解析不推断乘数、结算方式、交割股数、行权现金或规格确认。

2026-11-06 起，乘数查询与延迟报价并行、分别返回；没有近期成交也可取得有效规格。
规格响应必须与请求的代码、标的、到期日、认购／认沽及行权价一致，再接受来源明确
提供的正数 `multiplier`；支持现有精度内的小数乘数。单次规格查询最多 15 秒及 64 KiB，
404、缺字段、无效值或不匹配的身份不能生成可采用乘数。来源错误只记录脱敏信息。

查得乘数后自动填入空白或本页自动生成且尚未修改的字段，并显示查询值及来源。
手填值保留；与查询值不同时，未锁定草稿可明确点击“采用查询乘数”替换。已使用合约的
乘数仍锁定，不能因查询而改写。换合约身份会清除上个合约自动带入且未修改的乘数，
手填值保留供核对；迟到响应不得回填新草稿。查询不填写交割股数、行权现金、结算方式
或规格确认，不把取得乘数误称为已核对完整交割条款。

乘数和延迟参考价查询都须启用现有参考行情联网开关，并配置自己的免费 Basic 账户凭证。
请求只包含公开合约身份；未配置、无权限、未支持或未返回有效行情时说明原因，
未查得乘数时在字段旁提示手填；保留草稿，不用零价代替缺价，也不自动切换来源或开启持续行情。
合约代码及相关身份改变、切换账户或离开页面后，旧查询结果不得回填新草稿。

结果显示每单位权利金参考价、最近成交价口径、来源、实际成交时间及至少 15 分钟延迟，
说明实际成交可能更早，并沿用超过 24 小时提示。只有点击“填入参考价”才将结果写入
当前表单，用户仍可修改；不会填入真实成交价或期初总成本。此查询获得的是延迟窗口内
最新可用的历史成交，并不是用户
选择的期初日期或交易日期的历史价格。保存前仍须核对适用时点和合约资料；查询本身
不创建账户、证券、持仓或交易，不将候选或未提交价格写入账目。
