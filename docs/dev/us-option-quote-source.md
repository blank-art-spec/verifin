# 美股期权参考行情接入

更新：2026-11-05。

## 来源选择与边界

股票继续使用腾讯，基金继续使用指定招商来源。美股期权额外使用 Alpaca 的
[Snapshots API](https://docs.alpaca.markets/us/reference/optionsnapshots)，
固定请求 `https://data.alpaca.markets/v1beta1/options/snapshots`，显式选择 `feed=opra`。
该接口按完整合约代码返回 `latestQuote.bp/ap/t` 与 `latestTrade.p/t`；用户须拥有
自己的 API 凭证和 OPRA 数据权限。不自动注册、购买订阅或连接任何下单接口。
不回退为免费 indicative feed：官方说明其买卖报价经过修改，成交存在延迟，
不能将其展示为实际 OPRA 买卖价格。

复用原行情同步、手动刷新、前台五分钟自动刷新、逐证券采用与只读估值机制；
新增数据适配器不替换股票请求方式。构造适配器、打开设置或填写凭证都不自动
开启联网。应用无自有行情服务端；密钥只通过认证头发送给固定 Alpaca 主机。

以下调查仅是排除当前可用候选的证据，不是对全部供应方接口的断言：

- 原腾讯股票入口按 `usAVGO261204C00325000` 查询已确认存在的合约，HTTP 200，
  正文仅 `v_pv_none_match="1";`（21 字节）。不能直接把股票代码换成 OCC 代码；
  不能据此推论腾讯全部其他接口均不支持期权。
- Nasdaq 匿名 AVGO 期权链返回价格，但缺少对应报价字段的来源时间；不能把
  标的股票时间、HTTP 日期或抓取时刻当作期权价格时间。
- Cboe 延迟链包含合约和价格，但[官方报价页](https://www.cboe.com/delayed_quotes/avgo/quote_table)
  明确限制自动提取；未作为自动刷新来源接入。
- Tradier 有正式期权接口，但个人 token 可访问整个账户，公开应用另有合作认证要求；
  本轮不接入。Alpaca 也须用户遵守自身账户及数据权限，不将接口文档当作普遍使用许可。

## 配置与隔离

“参考行情 → 美股期权行情”录入 Key ID 和 Secret Key。只保留本次应用运行内存，
不写 SharedPreferences、SQLite、报价缓存、账目备份或日志；退出进程后须重填。
编辑页不回显旧凭证，两个字段均需填写，清除使用独立操作，取消不修改配置。
更换或清除前取消旧请求结果，清除此来源的旧缓存；股票和基金缓存不清除。
缓存清理失败不应用新凭证，输入留在页面供重试。网络失败只记录来源及数量，
不得记录认证头、请求原文或可能携带凭证的异常。

## 身份、价格与估值

仅接 USD、美国市场、完整 OCC 合约代码；校对代码中的标的根、到期年月日、C/P
及千分之一单位行权价，与用户录入的公开合约资料完全一致。首版只接受可直接
匹配普通字母标的的合约；调整合约、类别股映射和 TEST 示例不猜代码，保留手填。
不向接口发送数量、成本、保证金、交割说明、账本账户或备注。

每批最多 20 个合约、15 秒、512 KiB；固定 HTTPS 主机、路径和 feed，不跟随重定向，
401/403/429 不变更身份或转至别的服务器重试。源 JSON 价格保留十进制文本，
按准确合约键匹配响应；未知时间、错误日期、明显未来时刻、无效价格不进入估值。
有效双边价格优先采用中间价，否则采用带来源时间的有效成交价；时间来自对应
字段，不能用抓取时间补齐。乘数只在持仓估值中应用一次。

股票/期权的有效参考价距今超过 24 小时会在行情列表和持仓报价依据中提示。
提示不推断休市/停牌状态，不因周末将最近可用价自动作废；基金日净值不套用此阈值。
现金、持仓数量、成本、真实交易与手填后备价始终不因刷新而改写。
