# 美股期权参考行情接入

更新：2026-11-07。

## 当前来源：Nasdaq 免凭证期权详情

主应用固定装配 `Nasdaq Options`，不需要账号、API Key 或浏览器 Cookie。
依据 Nasdaq 详情页实际使用的请求，访问
`https://api.nasdaq.com/api/quote/{underlying}/option-chain?assetclass=stocks&recordID={root}--{YYMMDD}C{strike}`。
同一到期日、行权价的 Call/Put 共用一次详情，分别匹配各侧完整合约代码后取
`optionChainListData.LastSale.value`；不用标的股票价格、买卖中间价或成交量替代。

2026-11-07 电脑匿名请求：AVGO 期权链和完整详情均 HTTP 200，详情确认
`AVGO261109C00265000` / `AVGO261109P00265000` 两侧有正价格；
另按日期核对 AVGO 2026-12-04、325 行权价的认购/认沽。SOFX 查询为 HTTP 200
但业务状态 400、`Symbol not exists.`，必须作为缺价处理，不能把 HTTP 成功当有价。
真实详情及请求来源记录随测试夹具保留；这些检查不代表全市场覆盖或 Android 验收。

详情 `timeStamp` 未定义为逐笔成交时间，实测返回周六的时间，不写入 `lastAt`。
报价显式标记 `sourceTimeUnknown`，显示“报价时间未知”和独立抓取时刻；
未承诺实时或固定 15 分钟延迟。只有显式未知标记的期权正成交价可作参考估值，
默认缺时间、股票及基金的原校验不放宽。源时间已知仍按源时间排序，未知观察仅按
抓取时间替换同来源缓存，不能据此声称行情变新。

所有已保存、身份一致的美元美股期权都能尝试刷新，包括零持仓与已平仓合约，
不再限定 AVGO 等个别标的。实际挂牌、过期数据和调整合约覆盖取决于 Nasdaq；
TEST、无效日期或代码与到期日/方向/行权价不一致不发请求。资产估值仍只计算真实
持仓。联网与前台自动刷新默认关闭，逐合约选择采用；后台、锁屏和撤销会话停止请求。

每批最多 20 个合约、最多 3 个在途请求，共用 15 秒与累计 512 KiB 预算。
固定 HTTPS 主机，不跳转、不带凭证；401/403/429 停止尚未开始的请求，来源至少暂停五分钟，遵守更长的 Retry-After，暂停覆盖后续批次与其他账户。
单合约失败不丢弃其他成功报价；失败/缺价合约的旧 Nasdaq 缓存失效，回到原手填价，
手填资料、成本、数量、现金和真实交易不改。整轮取消不落入部分更新。

Nasdaq 不提供本入口可验证的数字权利金乘数，乘数及交割资料保留手填与原确认流程。
旧 Alpaca 适配器、凭证设置与存储入口、在线乘数查询已删除；旧密文不主动删除，也无读取或使用入口。
旧 Alpaca 缓存不参与新来源估值。主动保存历史依据时保留空报价时间、未知标记与
独立抓取时刻，完整备份升级 JSON v18，继续读取 v1–v17；SQLite 仍为 v30，
无需新增列。已有 v17 样例备份继续作为兼容输入，不改写用户正在编辑的模板。

`approved: false` / `researchOnly: true` 沿用现有来源准入标记；匿名接口可用不表示
已取得 Nasdaq 的数据分发授权，不能把来源状态宣称为正式许可已审核。

返回真实美股期权报价，成功后再接入所有已配置合约的刷新及手填后备。当前未取得
成功报价，当时没有改动行情来源；随后另行验证并接入了上方 Nasdaq 来源。

通过当前电脑网络执行了少量只读请求，使用明确标识的 `VeriFin-QuoteProbe/1.0`
客户端；未使用登录 Cookie、代理轮换、浏览器身份伪装或第三方转发服务：

| 请求阶段 | 实际结果 | 可以得出的结论 |
| --- | --- | --- |
| 无会话请求 `query2.finance.yahoo.com/v7/finance/options/AVGO` | HTTP 401，`Invalid Crumb` | 不能直接作为无状态匿名 URL 查询 |
| 按 yfinance 的正常匿名会话流程请求 `fc.yahoo.com` | HTTP 404，同时发放 1 个 Cookie | 取得匿名会话，不代表取得行情或账号授权 |
| 同一会话请求 `query1.finance.yahoo.com/v1/test/getcrumb` | HTTP 429 | 会话校验阶段被限流，停止请求，没有继续请求期权链 |

会话流程依据 [yfinance 的请求实现](https://github.com/ranaroussi/yfinance/blob/main/yfinance/data.py)，
行情字段依据[期权链实现](https://github.com/ranaroussi/yfinance/blob/main/yfinance/ticker.py)。
验证仅说明本轮普通客户端的匿名流程未能取得报价，不能据此断言 Yahoo 永久不能
免 Key 使用，也不能声称完整 yfinance 客户端、Android 直连或全部合约已经验证。
Cookie 与校验信息未写入报告、日志或账目数据；没有修改应用网络配置。

后续接入仍须先获得真实响应，核对完整合约代码、币种、价格及其实际成交时间，
并验证多标的、多到期日和逐合约失败隔离。`lastTradeDate` 不能充当买卖报价时间，
`contractSize` 不能直接代替数字乘数。取价失败须保留手填价格和合约资料，不能用
零价补缺。这是 Yahoo 验证阶段的边界，当前全部已配置合约刷新已由 Nasdaq 实现。

该 Yahoo 验证阶段只更新记录，没有改动应用代码、运行 Flutter 功能测试、生成安装包或发版。
