# 招商官方美元货币基金接口：诊断研究

验证日期：2026-10-28。本文记录招商证券官方网站公开使用的基金接口、指定 B 类身份、
开发机与 Android 模拟器的实际匿名请求，以及诊断研究的使用边界。
前一轮[天天基金验证](money-fund-api-research.md)的数据错误与身份映射缺口继续保留，
不能用本轮另一来源的成功改写其结论。股票来源见[腾讯股票研究](public-quote-research.md)。

**本轮已确认：Android 15 模拟器可以不经自有后台、无需账号或 API Key，直接向招商官方
接口发出匿名 POST，取得招商美元货币市场基金 B 类的最新单位净值和 543 个历史观察点，
也能下载同一基金的 XLS 历史文件。本次得到的是单位净值，不是万份收益或七日年化。**

## 官方身份与来源定位

指定份额为**招商美元货币市场基金 B 类**：

| --- | --- |
| ISIN | `HK0001039582` |
| 基金及份额 | CMS USD Money Market Fund，B 类 |
| 实际币种 | USD |

第 12 页；分派是否发生、频率与金额由管理人酌情决定，不能套用内地每日收益结转模型。

**接口响应本身没有回显 ISIN、基金参数或币种。** 本次身份链是“官方产品资料 → 固定基金
参数 → B 类键”，不能声称每次响应都再次验证了 ISIN。诊断适配只能接受已经核对的
`HK0001039582`、B 类与 USD，不能按模糊名称、相似代码或任意份额键扩展匹配。
若将来官网参数、份额结构或币种含义变化，应停止使用并重新核对，不能回退到列表首项。

## 实际请求规格

两个地址均固定使用 HTTPS POST：

| 用途 | 地址 | 实际响应 |
| --- | --- | --- |
| 最新值及完整历史 | `https://cms.cmschina.com.hk/api/v1/fund/netVal-info` | JSON，业务成功为 `code=0` |
| 官方历史下载 | `https://cms.cmschina.com.hk/api/v1/fund/netVal-export` | `application/octet-stream`，附件名 `chart.xls` |

请求头使用 `Content-Type: application/json`，请求体为以下 55 个 UTF-8 字节：

```json
{"lang":"zh-CN","fundName":"CMS_USD_Money_Market_Fund"}
```

不需要登录、Token、API Key、Cookie 或 Authorization。请求不发送账本、账户名称、
账户 ID、余额、持仓数量、成本或备注。没有开放任意 URL 或用户输入的基金接口参数。

本轮开发机探测关闭 Cookie、默认凭证及重定向；单次 25 秒、响应累计上限 2 MiB，
保留系统证书校验。Android 也使用 25 秒和 2 MiB 上限，遇重定向或错误即停止，未重试绕过。
这两个上限是本次探测规格，应用适配器的具体限额以当前实现为准。

## JSON 字段与精度

`netVal-info` 的顶层为 `code`、`message`、`result`；本次成功为 `code=0`、`message="OK"`。
`result` 包含：

| 字段 | 意义与解析约束 |
| --- | --- |
| `dateList` | `yyyyMMdd` 来源日期；与各份额净值数组按索引对应，不是逐笔交易日期 |
| `fundClassDataList` | 各份额的 `key`、`name` 与精确文本 `data`；B 类必须明确按键匹配 |
| `lastUpdate` | 官网给出的最新净值日期；本次为 `20261027`，只有日精度 |
| `lastValMap` | 按份额键列出的最新单位净值文本；B 类必须与历史数组末项一致 |

本次 `dateList` 与 B 类 `data` 均为 543 项，日期严格升序，全部 B 类净值是有效正十进制文本：

| 观察点 | 来源日期 | B 类单位净值 |
| --- | --- | --- |
| 首项 | 2024-08-09 | `100` USD/份 |
| 末项 | 2026-10-27 | `109.8150` USD/份 |
| `lastValMap.B` | 2026-10-27 | `109.8150` USD/份 |

净值字符串的精度须保留，不能先转 `double` 或固定三位小数重写。
例如本次来源文本 `109.8150` 的价格是 `109.815`，不能截为 `109.81` 或自行四舍五入为
`109.82` 后再参与持仓估值。显示格式与精确计算分开，尾零不构成另一个价格。
缺值、非法日期、数组长度不符或最新值不一致时不能填零，也不能把上一份额的值借给 B 类。

`lastUpdate` 与 `dateList` 只给出日精度，不能凭空补出“净值在 00:00 发布”的事实，
也不能把本机抓取时间当作来源净值时间。该价格是已披露的单位净值，不能标为实时成交价。
接口未给万份收益、七日年化或用户实际到账收益，本次没有从净值差额派生这些字段。

`netVal-export` 的响应头为附件 `chart.xls`，文件前八字节为 `d0cf11e0a1b11ae1`，
是 OLE/BIFF Excel 文件，**不是 CSV，也不是 JSON 下载链接**。Android 按原始字节读取，
没有把二进制文件按 UTF-8 解码。导出接口只用于这次研究对照，日常参考价刷新无需重复下载 XLS。

## 诊断接入与账务边界

诊断研究只匹配本次核对的 B 类份额，用于最新单位净值的只读参考估值及历史派生；原手填后备价
保留。公开 NAV 历史随既有设备报价缓存保存，按各净值日的真实持仓、投资事件和历史现金，
自动计算净值日参考收益、基金历史市值及有充分价格依据时的账户参考资产。
联网和这些计算不修改现金、交易、数量、成本或股息，**不生成收入流水，也不自动生成权威
`InvestmentValuationSnapshot`**。用户主动保存的估值依据仍是另一条独立操作。

这批公开历史是可重建的设备缓存，不新增 SQLite 字段，不进入完整账目备份，既有 JSON v13
不因加入设备缓存而再次升级。删除或修改真实交易后实时重放计算，不把旧图上的派生金额当作
新的权威记录；清除缓存、数据缺日或来源不可用时不能编造历史，也不把今天的价格回填到过去。
这不等于已支持基金申赎确认、银行到账核准或每日收益结转。

买卖、修改或删除交易时，同一账户、稳定基金身份、币种及当前可用来源仍匹配且净值观察有效的
公开历史可保留，并绑定新的账务上下文重算；股票报价原有的修订失效规则不因此放宽。
基金全部卖出后仍可查看并重放已缓存的基金历史，不要求重新买入。若已采用的净值历史尚未覆盖
最后一笔基金事件的香港日期，可补查公开净值；覆盖后不因空持仓而持续自动联网。
基金身份被删除、币种变化、来源门禁撤销或缓存无效时，仍不能借旧历史恢复不再允许的能力。
基金交易表单的后备价未变时保留既有净值采用；明确修改后备价才切回手填。
清仓后保留原基金身份的再次买入入口。最新净值日早于卖出日时，旧日仍按当日真实份额计算，
等待来源公布后续净值，不把今天的零持仓提前回填到旧日。

### 净值日参考收益与历史参考资产口径

只返回官网实际发布的净值日期，按香港该日结束时的真实持仓重放，不为周末、节假日或来源缺日
插值。相邻两个净值日之间即使跨多个自然日，也作为一个观察区间，不分摊成每天已到账收益。

| 派生项 | 当前口径 |
| --- | --- |
| 基金历史市值 | 该净值日实际持有份额 × 该日官方单位净值 |
| 净值日参考收益 | 本期市值 − 前一净值日市值 + 区间内该基金投资事件现金腿；买入现金腿为负，卖出、现金分红为正，费用为负，避免把本金进出当收益 |
| 缺少区间基准 | 第一个可观察点没有前一点基准时显示未知；发生持仓转入/转出的区间不猜收益，后续有完整基准的区间再恢复计算 |
| 累计参考盈亏 | 该基金已实现盈亏 + 净分红与费用 + 当前未实现盈亏；成本或已实现口径不完整时显示未知 |
| 账户历史资产 | 真实历史现金 + 本基金该日市值 + 其他证券有同日有效价格依据的市值；缺其他证券价格时完整账户资产未知，并列出缺价证券 |

因此，同一账户同时持有 GOOG 等股票时，只有基金净值历史并不足以生成整个账户的历史资产。
基金自身市值、参考收益仍可展示；股票没有同日有效的用户估值依据时，不使用今日 GOOG 价格
填补历史总额。这些派生数值不表示管理人已确认向用户派发或已到账的金额。

来源仅在实际 debug、独立 `diagnostic` flavor、显式 `PUBLIC_QUOTE_RESEARCH=true`
三项同时满足时装配，与腾讯研究来源共用既有联网授权、前台会话、逐证券采用和缓存门禁。
保持 `approved: false`、`researchOnly: true`，普通渠道、release/R8 和缺参数构建均不可借旧缓存
恢复研究来源。具体实现及后续验收见[参考行情阶段 4](securities-stage04-implementation.md)。

本轮匿名请求成功只确认技术可达、已核对份额及公开字段；尚未取得允许第三方应用自动使用、
缓存或分发这些数据的明确正式发布依据，不把“无需登录”视为发布授权，也不承诺覆盖其他香港基金。
正式渠道仍须另行完成使用条件、字段稳定性、更新频率与 Android 应用接入验证。
