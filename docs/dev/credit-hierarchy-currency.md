# 父子账户、参考折算与统一还款

本轮实现口径（2026-10-18）覆盖旧多币种文档中的「全部历史统计冻结」「仅离线汇率」约定。

## 账户与历史兼容

- `CreditAccount` 是真实信用卡/信用平台的父主体，`Account.creditAccountId` 关联各币种子账户。交易只引用真实 `Account.id`，父主体不记收入或支出。
- 资产列表按父主体展示信用账户，点击查看子账户及合并流水。父详情以账本本币估值，共享额度继续显示实际设定币种。首页聚合也采用账本本币。
- 父账户流水先按子账户 ID 合并（内部转账只出现一次）、日期排序，再筛选收支和截取最近 20 条。子账户详情继续可访问。
- 启动和恢复旧备份时，对「招行卡.人民币」「招行卡.美元」等明确名称、相同账本且配置相容的旧主体自动归并。账户/交易 ID、原币余额、锚点、账单、退款、附件和标签引用保持不变。重复归并不改变结果。
- 重复币种、卡尾号/账期冲突、用户自定义父主体、或拆分现有主体的情况不猜测合并；资产页提示核对，可在原子账户详情中选择父主体。新挂接不允许同父主体重复币种。
- 选择父账户记账后，交易币种决定真实子账户；缺少该币种时明确确认创建。选择具体子账户仍可表示银行实际以该账户币种结算。填本币参考额不会把美元消费移入人民币子账户。

## 金额与统计

`amount/currencyCode` 是原交易金额，`accountAmount` 是账户实际变动，转账另有 `toAccountAmount`。`referenceBaseAmount` 只表达用户明确填写或来源明确提供的账本本币折算额。`baseAmount` 保留作旧缓存，不再作为所有统计的唯一权威值。

- 外币流水未填参考额时只显示原币，不显示自动估算的折算额/消费时汇率。填写后显示原币、参考额、参考额÷原币计算出的汇率。
- 统计、分类、预算、项目、报表、只读 AI 查询与小组件读取 `projectStatisticsCurrency` 只读投影：本币直接取原金额；外币优先参考额，否则按查看时最新有效汇率换算。更新汇率不修改原始交易、账户实际金额或参考额。
- 已到账退款在同一投影中计算后重建原支出退款净额；未到账退款不冲减支出。原币退款上限和余额到账日期规则保留。
- 手填/导入来源的旧冻结金额在 v27/旧 JSON 恢复时转为明确参考额；旧汇率表自动计算缓存不自动确认为手填。新导入只有显式本币额、实际本币入账额或显式汇率才固定；普通自动转换仍随最新汇率统计。
- 旧版本的 `manual/imported` 没有逐字段的确认标记，无法进一步分辨当时手填的是哪一层金额。迁移保守保留该来源已有的冻结本币值，避免丢失历史结算事实；用户可在详情清除参考额，改用最新汇率统计。
- 当前资产、负债始终按实际剩余原币余额和最新汇率估值，不按消费参考额推算。缺汇率返回缺失币种，统计页提示汇总不完整，小组件金额显示缺失状态，禁止 1:1 猜测。

## 汇率联网

- 使用 Frankfurter v2 `GET /v2/rate/{foreign}/{base}`，无需 Key 或自有服务器。返回供应方的每日参考汇率，不承诺盘中实时行情。
- 自动更新默认关闭，用户开启后开屏/回前台每天检查一次；设置页支持手动更新。只请求币种（历史查询另带日期），不发送金额、账户名称、卡号或流水。
- 记录供应方生效日和设备同步时间。手填/导入的同币对同日汇率优先；失败保留缓存。网络等待后重新合并最新内存快照，再通过串行写队列提交，防止覆盖等待期间的手工修改。
- 汇率表进入账本备份；自动更新开关、尝试日期、同步时间属于设备偏好，不进入备份。初始化关闭自动更新；遗留日期键不包含账务数据。

## 统一还款

还款页首项为范围，默认「当前待还金额」，另可选「全部待还金额」。按每个子账户原币分别预填，允许调整。扣款账户保留「无账户转账还款」；跨币种可按最新汇率预填并确认各币种对应的实际扣款分摊，页面显示实际扣款合计。

验证依据实际分配，不能通过改选项绕过：

1. 当前各币种账单全额还清，且未超出当前范围：不要求补参考额，当前账单结清；未出账欠款保留。
2. 少于当前任一币种待还：检查当前范围内仍未结清的外币消费。缺参考额列出逐笔「去补齐」，整次还款不能保存。外币相对账本本币判断。
3. 超出当前待还（含选择全部待还）：额外范围内的未结清外币消费必须补参考额，当前全额豁免不扩展到未出账部分。
4. 各币种按原币到账、按最早到期顺序分配正式账单。还款不计收支，不删除消费、不伪造余额锚点。全部真实欠款归零才完整结清。

同次还款的转账使用 `repaymentBatchId` 关联。每个币种只扣其分摊额，合计扣款一次；交易、账单、分配通过 `saveCreditAggregate` 同一事务提交。失败保留原状态，草稿 ID 重试幂等。修改先撤回旧分配再整体替换；删除任一批次记录整体撤回。普通交易编辑接口拒绝单独改写批次成员。

历史购汇兼容：同一父账户内不同币种子账户之间、具有两端实际金额的购汇转账会转移原币债务。转入端抵扣尚无正式账单覆盖的外币旧账；转出端在未被正式账单覆盖时形成对应币种待还，银行出账日购汇计入当天账单。该转账不作为父账户外部还款，不修改正式账单已还金额，也不改变原始流水。没有正式账单时的未出账消费同样使用账户原币金额及实际到账退款，不能把本币统计折算额标为外币。

银行分期还款本轮不做。
