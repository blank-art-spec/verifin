# 期权阶段 3：当前实现与验收

日期：2026-10-24。开发分支沿用 `codex/securities-trading-quotes-20261023`，股票基线为 `8d73bb7`。
总体范围见 [开发方案](securities-trading-plan.md)，固定数字和完整操作见 [B04–B05、A07–A11](securities-trading-acceptance.md)。

## 本轮行为

- 原币投资账户支持认购/认沽的买入开仓、卖出平仓、卖出开仓、买入平仓；张数为正整数，多空分别持有和分摊成本，不自动抵销。
- 期权持仓按“张数 × 用户填写的权利金乘数 × 参考权利金”估值；股价、每张交割股数、每张行权现金不混入这个乘积。手填价格仍是持续参考价。
- 冻结保证金按每个合约的用户确认绝对额记载，留空不变、明确填 0 才释放；不产生现金腿，也不从净值重复扣除。可用参考现金为现金减冻结额，不是券商购买力。
- 无价值到期必须明确确认且日期不早于合约到期日。缺行情、零报价或超过到期日仅显示待确认，仍保留数量及成本。
- 现金交割录入指定张数的实际原币总额及费用，不再乘张数或乘数；多头收款、空头扣款，成本结转为已实现盈亏。
- 实物行权/指派将期权关闭、股票增减、行权现金和费用作为一个事件重放并一次保存。四类权利金成本归集遵循总体方案 5 节；期权关闭时不重复确认这份权利金的盈亏。
- 覆盖不足的空头认购指派只有另行确认后才生成不足部分的股票空头；已有覆盖部分按原股票成本出售。股票不足的多头认沽行权被拒绝，保留草稿。
- 当前支持同币种、单一股票交割及已确认的现金交割合约。非标准篮子/不同币种等结构保留资料与持仓，拒绝部分结算。可以手建已核对的调整合约，分别填写乘数、实际交割股数及行权现金。

## 规格与数据约束

`OptionContract` 在原 `StockSecurity` 中作为可选规格；保留现有类名和股票 ID，期权 ID 使用 `市场:option:完整代码`，不能与股票代码混淆。字段说明：

| 字段 | 意义与约束 |
| --- | --- |
| underlyingId | 同账户、同市场、同结算币种的股票定义引用 |
| expiry / right / strike | 用户核对的到期交易日、认购/认沽及行权价身份资料；日期按明确交易日比较，不推算交易所时区或自动到期 |
| premiumMultiplier | 每单位权利金乘数，无固定 100 默认值；允许明确的小数乘数 |
| deliverableShares | 每张实际交割股数；可与权利金乘数不同 |
| exerciseCash | 每张实际行权现金总额；调整合约不能从行权价乘交割股数猜测 |
| settlement | 单股实物、现金或不支持/待补全 |
| specification / confirmed | 规格核对依据和用户确认状态；未确认不能结算，公开行情验证不会代填或确认 |

定价身份一旦使用不能改写到期日、权利、标的或乘数；结算前可补齐交割资料，已结算的交割方式/股数/现金也锁定。标的股票拆股不会按股票比例静默改期权；当时仍有期权持仓则标记待处理，拒绝沿用原规格继续交易或实物交割。

实物交割需要明确的期权成本；未知期初成本可先通过现有“补齐期初成本”入口填写。导致负购股成本或负股票空头开仓所得的非常规分配暂拒绝，保留待核对，不伪造零成本。

SQLite 仍为 v28 的 `investment_portfolios(id, book_id, payload)`，没有修改表结构或历史迁移。合约规格和事件新增字段在同一聚合文本行内；JSON 完整备份升至 v11，旧 v10 股票聚合缺字段使用 null/false，v1–v9 的原兼容语义保留。新期权备份由支持 v11 的版本恢复，不承诺旧应用读取新格式。

## 页面与方法导航

从投资账户详情进入投资页，启用现金后点“期权交易与结算”。新建时手填完整合约、标的、到期日和乘数；也可选择本账户的已有合约。没有联网搜索或自动创建真实合约。

填写实际事件、方向及确认项后先点“预览结算后现金与持仓”，核对现金、冻结额、净值和各项多空数量/成本，再保存。修改任何字段、动作或日期都会废弃预览，必须重做；Controller 保存时再重放当前权威数据，过时预览不会绕过校验。取消零落库，保存失败留在草稿。已有事件点按可编辑或经公共确认框删除；会破坏后续持仓或交割的改动整笔拒绝。

| 入口 | 源码及职责 |
| --- | --- |
| 规格与映射 | `models/option_contract.dart`、`models/investment.dart`，精确文本及旧字段默认值 |
| 纯计算 | `investments/option_projection.dart` 是 `stock_projection.dart` 的领域 part，共用稳定顺序、数量/成本池、现金腿和估值；`securityPositionValue` 统一股票与期权乘数 |
| 命令与预览 | `previewOptionEvent`、`saveOptionEvent`、`saveOptionSpecification` 复用现有串行队列及原子聚合保存；预览零写入，失败不发布内存 |
| 用户操作 | `pages/option_editor_page.dart`，复用实色页面骨架、锚点单选、日期、统一确认及本地化输入；`InvestmentPage` 同时显示股票与期权 |

现金核对仍只截断现金腿，不改变股票/期权重放。实物交割只有一个稳定事件 ID，锚点的兼容 `stock:` 前缀涵盖所有投资事件，同刻补录规则保持不变。
